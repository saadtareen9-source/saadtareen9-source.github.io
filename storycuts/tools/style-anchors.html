StoryCuts

Official style references

Each built-in style gets one official reference image. It's attached to every character and scene drawn in that style, so the look stays the same for every user, every time. It's also the thumbnail on the style slider.

  1. Make sure your OpenAI key is saved on the main StoryCuts page (API keys).
  2. Click Draw on a style. Redraw until you love it. Every style draws the same scene, so you can compare them.
  3. Click Download on the ones you're happy with and send the files to Claude. They'll be added to the site.
